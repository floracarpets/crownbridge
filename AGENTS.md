# Project instructions

The main goal is to build Crownbridge as a real estate website. Every user-facing page must adapt to phones, tablets, laptops, and large desktop displays, with accessible navigation and usable property content at each size.

For React implementation, frontend reviews, public pages, SEO, and marketing features, read and apply [.agents/skills/react-seo-marketing/SKILL.md](.agents/skills/react-seo-marketing/SKILL.md).

Use Context7 for library documentation, code generation, and setup or configuration work. Resolve the library first, then query documentation relevant to the installed version. If Context7 is unavailable, disclose that and use official documentation rather than claiming a lookup occurred.

The project currently uses React with Vite and JavaScript. Keep changes proportional to the request; the skill does not itself authorize a framework migration or analytics installation.

Run `npm run build` after application changes. Run any relevant lint, type, or test scripts when they exist.
